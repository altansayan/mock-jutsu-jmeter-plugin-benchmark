1 Bu Benchmark Ne Ölçtü?

Wave test'in ölçtüğü şey saf fonksiyon üretim süresi. Her sampler, JMeter SyncTimer (barrier) ile tetikleniyor — tüm thread'ler aynı anda başlıyor.

Ölçüm = System.nanoTime() farkı / 1000 → mikrosaniye cinsinden kayıt.
BeanShell parse süresi (~2 ms) dışarıda bırakılıyor — sadece fn.execute() çağrısı ölçülüyor.

setUp Thread Group — Heavy Type CSV Üretim Scripti

JSR223 Sampler · scriptLanguage: beanshell · setUp Thread Group · 1 thread · 1 loop  |  Not: JMeter 5.6.x + Java 25'te Groovy çalışmıyor (ASM sınır dosyası v69 uyumsuzluğu). BeanShell zorunlu.

import com.mockjutsu.jmeter.functions.*;
import org.apache.jmeter.engine.util.CompoundVariable;
import java.io.*;

int N = 1000; String D = "C:/load-test-data/"; new File(D).mkdirs();

// w(fn, "tip|TR", "dosyaadi") → D/dosyaadi.csv (N satır, UTF-8)
void w(fn, String t, String f) throws Exception {
    java.util.List p = new java.util.ArrayList();
    p.add(new CompoundVariable(t)); fn.setParameters(p);
    PrintWriter pw = new PrintWriter(new OutputStreamWriter(
        new FileOutputStream(D+f+".csv"),"UTF-8"));
    pw.println(f);
    for (int i=0;i<N;i++){String v=fn.execute(null,null);
        pw.println(v.contains(",")||v.contains("\n")?"\""+v.replace("\"","\"\"")+"\"":v);}
    pw.close(); log.info("[mock-jutsu] "+f+".csv ("+N+")");
}

MockJutsuOidcFunction       oidc = new MockJutsuOidcFunction();
MockJutsuWalletFunction      wlt = new MockJutsuWalletFunction();

Pratik Örnek — İsim Soyisim, Kart Numarası, IBAN, Bakiye (tek CSV)

Tek bir CSV dosyasına 4 kolon, N satır. ${fullname} ${cardnum} ${iban} ${balance} değişkenleri ana testte kullanıma hazır.

import com.mockjutsu.jmeter.functions.MockJutsuIdentityFunction;
import com.mockjutsu.jmeter.functions.MockJutsuFinancialFunction;
import org.apache.jmeter.engine.util.CompoundVariable;
import java.io.*;

int N = 1000; String FILE = "C:/load-test-data/musteri.csv";
new File("C:/load-test-data/").mkdirs();

MockJutsuIdentityFunction  id  = new MockJutsuIdentityFunction();
MockJutsuFinancialFunction fin = new MockJutsuFinancialFunction();

java.util.List pId = new java.util.ArrayList(); pId.add(new CompoundVariable("fullname|TR")); id.setParameters(pId);
java.util.List pCn = new java.util.ArrayList(); pCn.add(new CompoundVariable("cardnum|TR"));
java.util.List pIb = new java.util.ArrayList(); pIb.add(new CompoundVariable("iban|TR"));
java.util.List pBl = new java.util.ArrayList(); pBl.add(new CompoundVariable("balance|TR"));

PrintWriter pw = new PrintWriter(new OutputStreamWriter(new FileOutputStream(FILE),"UTF-8"));
pw.println("fullname,cardnum,iban,balance");
for(int i=0;i<N;i++){
    String name = id.execute(null,null).replace(",","");
    fin.setParameters(pCn); String cn = fin.execute(null,null);
    fin.setParameters(pIb); String ib = fin.execute(null,null);
    fin.setParameters(pBl); String bl = fin.execute(null,null);
    pw.println("\""+name+"\","+cn+","+ib+","+bl);
}
pw.close();
SampleResult.setResponseData(N+" müşteri → "+FILE,"UTF-8");
SampleResult.setSuccessful(true);

Bu TPS rakamları ne anlama geliyor?
10.000 TPS = saniyede 10.000 banka transferi veya kart işlemi simülasyonu. Türkiye'nin en büyük ödeme sistemleri günde 5–10 milyon işlem yapar (57–115 TPS ortalama). mock-jutsu ile 10.000 TPS senaryosu pik yük testlerini bile kapsar ve gerçekçi finansal veri üretir.

7 Sonuç: Önerilebilir mi?

✅
Evet — Fast/Medium tip kullanımı için kesinlikle önerilir
Rakip çözümlere (Faker.js JMeter custom sampler, Manuel CSV, Random() calls) göre avantajları:
  • Standart uyumu: Luhn, IBAN, TCKN, BIC checksum'ları gerçek — 90+ ülke ID formatı destekli
  • Performans: 0.03–0.05 ms — yük testi zamanlamalarını etkilemiyor
  • Tekrarlanabilirlik: Aynı JMX, farklı ortamlarda aynı veri kalitesini üretiyor
  • Bakım kolaylığı: Tek satır değişikliğiyle farklı ülke/format — CSV hazırlamaya gerek yok
⚠️
Önerirken belirtilmesi gereken kısıtlar
  • İlk çalıştırmada setUp warmup zorunlu — bu repo'daki JMX'e eklendi
  • Heavy tipler per-request kullanılmaz — setUp + CSV pattern'ı dökümanlanmalı
  • JMeter 5.6.x + Java 25 kombinasyonunda Groovy uyumsuz; BeanShell veya JSR223 + cacheKey aktif olmalı
  • BeanShell overhead (parse/execution) bu benchmark'ın test süresini uzatmış — gerçek test senaryosunu temsil etmiyor
