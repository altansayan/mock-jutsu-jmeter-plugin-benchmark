Soru 3
Lazy-init spike'ları var mı? (ilk çağrı şişirilmiş süreler gösteriyor mu?)

Evet, belirli tiplerde var. En belirgin örnek: imei tipi avg=0.215 ms ama p50=0.031 ms. Ortalama, p50'nin 7 katı — ilk birkaç çağrının lazy-init gecikmesini (class loading, lookup tablosu init) ortalamaya kattığının işareti.

Lazy-init spike gözlemlenen tipler: imei (avg/p50 oranı 6.9×), color (avg/p50: 1.9×), slug (avg/p50: 1.4×). Bu tipler setUp warmup'tan geçirilmeli.
Soru 4
Warmup yardımcı oluyor mu? (setUp warmup, lazy-init spike'larını gideriyor mu?)

Evet. AllTypes-Wave.jmx'te setUp Thread Group (1 thread, 1 loop) tüm fonksiyonları sırayla bir kez çağırıyor. Bu JVM sınıf yüklemesini ve statik init bloklarını test başlamadan tamamlıyor.

Warmup olmadan (teorik)
  • İlk çağrı: class loading ~50–200 ms
  • İkinci çağrı: normal süre
  • p95 raporuna gürültü girer
Warmup sonrası (ölçülen)
  • Fast tipler p50: 0.027–0.045 ms
  • p95 drift (76 dk): +5.9% — kararlı
  • Spike'lar göz ardı edilebilir seviyede
Kanıt: Wave boyunca p95 trend: ilk bucket 0.102 ms → son bucket 0.108 ms. 76 dakika boyunca p95 +5.9% drift — istatistiksel kararlılık kanıtlandı.

CSV Ağır Tipler için setUp + CSV Üretim Scripti

JSR223 Sampler · scriptLanguage: beanshell · setUp Thread Group · 1 thread · 1 loop  |  Not: JMeter 5.6.x + Java 25'te Groovy çalışmıyor (ASM / class file v69 uyumsuzluğu). BeanShell zorunlu.

import com.mockjutsu.jmeter.functions.*;
import org.apache.jmeter.engine.util.CompoundVariable;
import java.io.*;

int N = 1000; String D = "C:/load-test-data/"; new File(D).mkdirs();

void w(fn, String t, String f) throws Exception {
    java.util.List p = new java.util.ArrayList();
    p.add(new CompoundVariable(t)); fn.setParameters(p);
    PrintWriter pw = new PrintWriter(new OutputStreamWriter(
        new FileOutputStream(D+f+".csv"),"UTF-8"));
    pw.println(f);
    for (int i=0;i<N;i++){
        String v=fn.execute(null,null);
        pw.println(v.contains(",")||v.contains("\n")
            ?"\""+v.replace("\"","\"\"")+"\"":v);
    }
    pw.close(); log.info("[mock-jutsu] "+f+".csv ("+N+" satır)");
}

MockJutsuOidcFunction   oidc = new MockJutsuOidcFunction();
MockJutsuAiFunction       ai = new MockJutsuAiFunction();

w(oidc, "oidc_token_set|TR", "oidc_token_set");
w(oidc, "jwks|TR",           "jwks");
w(ai,   "ai_embedding|TR",   "ai_embedding");
w(ai,   "ai_vector|TR",      "ai_vector");

SampleResult.setResponseData("4 tip → "+N+" satır → "+D,"UTF-8");
SampleResult.setSuccessful(true);
